# Rótulos de triagem

| Papel canônico | Rótulo no GitHub | Significado |
| --- | --- | --- |
| needs-triage | needs-triage | Aguarda avaliação do mantenedor |
| needs-info | needs-info | Aguarda informações do solicitante |
| ready-for-agent | ready-for-agent | Especificada e pronta para um agente |
| ready-for-human | ready-for-human | Requer implementação humana |
| wontfix | wontfix | Não será implementada |

Quando uma skill mencionar um papel canônico, aplique o rótulo
correspondente desta tabela.
